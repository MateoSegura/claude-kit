# Standards Mapping: NIST SP 800-171 Rev 2

**Version:** 1.0.0
**Status:** draft
**Last Reviewed:** 2026-02-28

## Purpose

Map claude-kit QMS government overlay processes to NIST SP 800-171 Rev 2 control families. NIST 800-171 provides the security requirements for protecting CUI in non-federal systems and is the technical foundation for CMMC Level 2. This mapping demonstrates how the QMS process architecture satisfies each control family.

## Mapping Legend

- **Primary:** The process directly implements or governs compliance with the control family
- **Supporting:** The process contributes evidence or activities that support the control family
- **Inherited:** The control is inherited from infrastructure or a base process
