# core-git

> **Role:** Knowledge · **Version:** 0.0.1

General-purpose git mastery reference. Auto-loaded with every team as a universal core skill.

---

## Skills Inventory

| Skill | Description |
|-------|-------------|
| `branching-strategies` | Git branching strategies -- trunk-based, GitHub Flow, GitFlow, release branching |
| `commit-conventions` | Commit conventions -- Conventional Commits, semantic messages, atomic commits, merge strategies |
| `advanced-operations` | Advanced git operations -- interactive rebase, cherry-pick, bisect, reflog, stash, worktrees, submodules |
| `monorepo-patterns` | Monorepo patterns -- sparse checkout, path-based ownership, affected-only CI, dependency graphs |

---

## Auto-Loading

This plugin is auto-loaded with every team via the `domain: "universal"` field in `ctl.json`.
