# core-testing

> **Role:** Knowledge companion · **Version:** 0.0.1

General-purpose testing philosophy — test pyramid, test doubles, coverage strategy, and TDD/BDD patterns for any software project.

This plugin is **auto-loaded as a companion** by role plugins that declare it. Do not launch it directly.

---

## Skills Inventory

| Skill | Domain Coverage |
|-------|----------------|
| `test-philosophy` | Test pyramid, testing trophy, cost-benefit analysis, property-based testing, what to test and what not to test, testing in production |
| `test-doubles` | Mocks, stubs, fakes, spies, dummies — when to use each, over-mocking dangers, dependency injection, sociable vs solitary tests, test isolation strategies |
| `coverage-strategy` | Line vs branch vs path coverage, mutation testing, coverage as a tool not a target, risk-based coverage allocation, coverage ratcheting |
| `tdd-bdd` | Red-green-refactor cycle, inside-out vs outside-in TDD, BDD with Given-When-Then, acceptance test driven development, transformation priority premise |

---

## Auto-Loading

This plugin is loaded as a companion by role plugins that reference it in their `ctl.json` companions list. All skills are injected into the role plugin's agent context at launch.
